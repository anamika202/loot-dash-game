# 💰 Loot & Dash - Multiplayer Bluff Game

A fast-paced, real-time multiplayer bluffing game built for the challenge. Outsmart your friends by choosing whether to **Collect** safe points or **Steal** from other players!

## 🚀 Features
* **No Login Required:** Friends can join instantly from any phone or laptop using a room code.
* **Real-time Sync:** Live updates as players lock in their secret moves.
* **High-Stakes Bluffing:** Balance safe collection with risky steals to top the leaderboard.

## 🎮 How to Play
1. **Create a Room:** Enter your nickname and click **Create Room** to get a unique room code.
2. **Join a Room:** Share the code with your friends. They enter their nickname and the code to join the lobby.
3. **Make Your Move:** In each round, secretly choose:
   * 🪙 **Collect:** Gain safe points (+10).
   * 🥷 **Steal:** Attempt to loot points from collectors.
4. **Win the Game:** Play through 5 rounds and see who has the highest score at the end!

## 🛠️ Tech Stack
* HTML5 / JavaScript (ES Modules)
* Tailwind CSS for styling
* Real-time synchronization
